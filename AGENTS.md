# Rules

## Git

- Commit subjects and PR titles: about two generic words, sentence case.
- No commit bodies or PR descriptions.
- No prefixes, scopes, or references outside this repo, including in branch names.
- No attribution (Generated with, Co-Authored-By, agent or session links).
- No emojis.

## Files

- No comments, tests, or documentation.
- Use Allman brace style where it fits.
- Avoid underscores in names where possible.
